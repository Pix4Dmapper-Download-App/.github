# Pix4Dmapper — Photogrammetry Processing on Windows
Pix4Dmapper is a photogrammetry application for Windows that turns overlapping images into measurable maps and 3D models.
Its guided workflow supports image import, processing, quality review, and the export of project results.

## Practical Tips for New Users

→ Begin with a small, representative image set to learn the processing workflow and review quality indicators before working on a larger project.
→ Keep source images and project files on fast local storage while processing, then organize exported results separately.
→ Check image overlap, sharpness, and coordinate information before starting a full reconstruction.

## Pix4Dmapper System Requirements

→ **Operating system:** A 64-bit Windows edition supported by the Pix4Dmapper release you install; confirm compatibility for Windows 11 in the current product documentation.
→ **Processor:** A modern multi-core 64-bit processor suited to sustained image processing workloads.
→ **Memory:** Enough RAM for the image count, image resolution, and reconstruction settings used in the project.
→ **Graphics:** A compatible dedicated graphics processor is recommended for visualizing detailed point clouds and 3D results.
→ **Storage:** Fast local storage with sufficient working space for source images, temporary processing data, and exported outputs.
